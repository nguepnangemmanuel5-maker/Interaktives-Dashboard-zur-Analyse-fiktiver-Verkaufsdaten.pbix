# Interaktives Dashboard zur Analyse fiktiver Verkaufsdaten

Interaktives Power-BI-Dashboard zur Analyse fiktiver Verkaufsdaten, mit Auswertung von Bestellungen, stornierten Verkäufen sowie der Aufteilung nach Produkt und Region.

## Inhalt des Dashboards

- **Suivie ventes** — Hauptseite: Kennzahlen (KPI-Karten), zeitliche Entwicklung der Verkäufe (Liniendiagramm), Aufteilung nach Kategorie (Balken- und Donut-Diagramm), Detailtabelle, Filter (Datum, Produkt, Region)
- **Vente annuler** — Analyse der stornierten Bestellungen
- **Infobulle vente par région** — individuelles Tooltip, das beim Überfahren mit der Maus angezeigt wird
- **Ruban vente par produit** — Ribbon-Chart zur Entwicklung des Produkt-Rankings

## Technologien

- Power BI Desktop
- DAX (Berechnungen und Kennzahlen)
- Datenmodellierung
- Individuelles Theme (Farb- und Layoutgestaltung)

## Datei öffnen

1. [Power BI Desktop](https://powerbi.microsoft.com/desktop/) installieren (kostenlos, nur Windows).
2. Die `.pbix`-Datei aus diesem Repository herunterladen.
3. Die Datei direkt mit Power BI Desktop öffnen.
